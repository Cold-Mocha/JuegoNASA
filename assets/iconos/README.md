# Iconos
Iconos de recursos del HUD (20×20 de diseño, exportados a 24 px). Cada uno usa el color fijo de su recurso:
salud `aurora-teal`, hambre `solar-coral`, sed y señal `comet-cyan`, radiación `nebula-magenta`, energía `star-gold`.
`tablet.svg` es el icono del TabletButton; `favicon.svg` el del sitio.
