# Motivos
Formas gráficas originales del sistema (no provienen de la plantilla de referencia ni de la NASA).

- `destello.svg`: destello de cuatro puntas en `star-gold`. Puntuación, chispas de recompensa y viñetas decorativas.
- `constelacion.svg`: muestra de patrón de constelación (líneas punteadas `constellation`, estrellas `ink-muted`) sobre `space-800`. Para fondos de menú; es decorativo, nunca lleva información.
