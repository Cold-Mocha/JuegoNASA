# Design system (copia local)
Versión navegable y viva: artifact **Michinautas** (Design System) en claude.ai — https://claude.ai/artifact/XQJ7QpQKxf4M2UKSSA6QQP

- `README.md`: libro de marca completo (voz, colores, tipografía, HUD, personajes, accesibilidad, uso legal).
- `tokens.json`: fuente única de verdad (colores por tema, tipografía, espaciado, radios, sombras, z-index).
- `tokens.css`: variables CSS generadas desde tokens.json (no editar a mano).
- `componentes.css`: todos los componentes `mn-*`.
- `componentes/<Nombre>/README.md`: guía de uso de cada componente.
