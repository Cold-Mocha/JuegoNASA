# AchievementToast
Píldora que anuncia un logro o insignia; borde y medalla en `nebula-magenta`.

## Reglas
- Entra desde arriba en `z-toast`, permanece 3.5s, sale sola; no bloquea el juego.
- Una a la vez; si hay varias, en cola.
- Expón el texto a lectores de pantalla (`role="status"` en web).
- El título dice qué logró el jugador, no el nombre interno del logro.
