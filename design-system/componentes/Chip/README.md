# Chip
Etiqueta compacta para la categoría de una misión o un dato breve.

## Categorías
`--science` (`comet-cyan`), `--eva` (`aurora-teal`), `--nav` (`nebula-violet`), `--bonus` (`nebula-magenta`), `--outline` (neutro, para nivel o metadatos).

## Reglas
- Texto `ink-dark` sobre relleno (≥5.3:1). Una o dos palabras.
- No son botones: si es interactivo, usa `Button --sm`.
