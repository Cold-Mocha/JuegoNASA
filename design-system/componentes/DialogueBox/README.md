# DialogueBox
Caja de diálogo de personaje: retrato circular, nombre en `star-gold` y texto `body`.

## Reglas
- Máximo 2 líneas por globo (~120 caracteres); dividir el resto en varios pasos.
- Texto con efecto máquina de escribir a ~40 caracteres/s; un toque/botón lo completa al instante y el siguiente avanza.
- Siempre muestra la pista de control (`.mn-key`) adaptada al dispositivo (A / Espacio / Toca).
- Va en `z-dialog`, anclada abajo con margen `space-6`.
- El consumidor aporta: retrato (ilustración propia del equipo), nombre y texto.
