# MiniStats
Píldora fija abajo al centro con los 3 valores que más cambian (salud, energía, radiación) para no tener que abrir el panel.

## Reglas
- Solo números y un punto de color por recurso; el detalle vive en el StatusPanel.
- `.is-crit` pinta el valor en `danger` y antepone ⚠.
- `title`/etiqueta accesible con el nombre del recurso.
