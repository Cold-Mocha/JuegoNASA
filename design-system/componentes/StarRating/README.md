# StarRating
Puntuación de misión con 3 estrellas de cuatro puntas (el destello de la referencia).

## Reglas
- Obtenida: relleno `star-gold`, borde `star-gold-deep`, brillo `glow-star`. Vacía: `space-600` con borde `line` (la forma sigue visible).
- En la pantalla de resultados aparecen una a una (stagger 250ms) con un "pop" de escala 0.6→1.1→1.
- Expón el total como texto ("2 de 3 estrellas").
