# TaskList
Lista compacta de tareas del día, fija arriba a la izquierda del HUD, con barra de progreso.

## Reglas
- Máximo 5–6 tareas por día; verbo en infinitivo + sala entre paréntesis.
- Completada: `.is-done` (teal, tachada). El orden no obliga: el jugador decide la ruta, y caminar entre salas es parte del costo.
- La cabecera muestra día de misión y lugar en `caption-mono`.
- En la nave, cada consola con tarea pendiente muestra un destello dorado flotante.
