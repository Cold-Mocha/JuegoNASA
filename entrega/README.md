Entregables finales de Michinautas, ordenados según la pauta oficial de la sede. [`Michinautas.docx`](Michinautas.docx) es el documento completo. Los archivos `.md` son cada pieza del formulario, listos para copiar y pegar.

| Paso de la pauta | Estado | Archivo |
|---|---|---|
| 1. Elegir desafío | Listo: Build a Junior Astronaut Mission Trainer | [`../DESAFIO.md`](../DESAFIO.md) |
| 2. Armar y registrar el equipo (máximo 6, todos inscritos y unidos en la sede) | Falta revisar que cada integrante esté unido al equipo en la web | |
| 3. Trabajar con datos reales y citarlos | Listo | [`03-DATOS-NASA.md`](03-DATOS-NASA.md) |
| 4a. Título y resumen | Listo | [`01-RESUMEN.md`](01-RESUMEN.md) |
| 4b. Demo: video de 30 s o 7 slides | Guion listo. Falta armar el video con los clips | [`02-DEMO.md`](02-DEMO.md) y [`06-VIDEOS.md`](06-VIDEOS.md) |
| 4c. Link al proyecto final | Listo, ver abajo | |
| 4d. Qué datos de la NASA usaron | Listo | [`03-DATOS-NASA.md`](03-DATOS-NASA.md) |

| 5. Pitch ante el jurado | Guion listo. La sede anuncia orden y formato | [`05-PITCH.md`](05-PITCH.md) |

## Plazos

- El líder del equipo envía el proyecto desde la web antes del domingo a las 11:00.
- Se puede editar hasta las 23:59 del mismo domingo.
- Sin envío no hay evaluación.
